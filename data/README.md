# Data

This directory documents the dataset used by the **Order Fulfillment & Pricing Profitability Analytics** project.

## Source

The source dataset is publicly available on Kaggle:

- **Dataset:** [INVENTORY MANAGEMENT ANALYSIS (SQL BASED PROJECT)](https://www.kaggle.com/datasets/harshadashirin/inventory-mangement-analysis-sql-based-project)
- **Author:** Harshada Shirin
- **Platform:** Kaggle
- **License listed by Kaggle:** CC0: Public Domain

The original source is referenced rather than redistributed in this repository. Keeping the provenance link is useful for reproducibility even when the dataset is released under a permissive license.

## Repository Data Policy

The source CSV files are **not committed to Git** and are intentionally excluded from the public repository.

Expected local layout:

```text
data/
├── README.md
├── raw/
│   ├── Customer.csv
│   ├── Employee.csv
│   ├── OrderDetails.csv
│   ├── Orders.csv
│   ├── Product.csv
│   ├── Region.csv
│   └── Warehouse.csv
└── processed/
    ├── order_analytics.csv
    └── shipped_order_analytics.csv
```

`raw/` contains the downloaded source files. `processed/` contains analytical outputs generated by the project code. Both are local working data and should remain excluded from Git unless there is a specific reason to publish a derived dataset.

## How to Reproduce

1. Open the Kaggle source page above and download the dataset.
2. Extract the seven CSV files into `data/raw/`.
3. Import the source tables into MySQL using the schema defined in the project SQL workflow.
4. Run the queries in `sql/analysis.sql` to create the analytical views and reproduce the SQL analysis.
5. Run the Python notebook in `python/` to generate the processed analytical files.
6. Use the processed output locally when refreshing the Power BI dashboard.

The repository therefore contains the **code, methodology, documentation, and dashboard outputs**, while the source data remains reproducible through its original public source.

## Data Provenance and Preparation

The project does not overwrite or modify the downloaded raw CSV files. Data transformations are performed during database import and analysis.

Examples of preparation applied in the project include:

- Parsing order dates into a database `DATE` field.
- Treating postal codes as text because postal codes are identifiers rather than numeric measures.
- Joining `Orders`, `OrderDetails`, `Customer`, and `Product` for transaction-level analysis.
- Deriving revenue, estimated cost, gross profit, gross margin, and price realization from the source fields.

The raw dataset should always be treated as the source of record for reproducing this analysis.

## Important Interpretation Note

The dataset is intended for SQL, business intelligence, and analytical practice. Financial metrics in this project are analytical calculations derived from the supplied fields and should not be interpreted as audited accounting figures or actual company financial performance.
